# Raw data

Place locally downloaded Istanbul hourly traffic files here.

The B40 Open Data Portal lists **Saatlik Trafik Yoğunluk Veri Seti / Hourly Traffic Density Data Set** and links it to the IBB Open Data platform. The listing states that the dataset contains hourly Istanbul location, density, and traffic information.

Raw files are intentionally Git-ignored. Record the source URL, retrieval date, license, and SHA-256 before processing.
