ISTANBUL GRAPHTRAFFIC AI — FIRST STEPS

1) Extract this folder.
2) In GitHub Desktop choose File > Add local repository.
3) Select the extracted `istanbul-graphtraffic-ai` folder.
4) If GitHub Desktop says it is not yet a Git repository, choose "create a repository" using this folder, or run `git init` once.
5) Repository name: istanbul-graphtraffic-ai
6) Recommended description is in GITHUB_ABOUT_SETTINGS.md.
7) Commit all files with message: Initial research-grade GraphTraffic AI scaffold
8) Publish repository to GitHub.
9) In GitHub Settings > Pages, deploy from branch `main`, folder `/docs`.
10) Run the synthetic smoke pipeline before adding real IBB data.

IMPORTANT: data/raw is intentionally excluded from Git. Do not upload third-party raw data unless its license explicitly allows redistribution.
