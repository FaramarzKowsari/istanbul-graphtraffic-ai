Preregistered graph-based Istanbul traffic forecasting

İstanbul GraphTraffic AI is a reproducible research project using public İBB hourly traffic data to study temporal forecasting, directed road graphs, adaptive connectivity and Dynamic Graph Transformers. A registered confirmatory Protocol v2 analysis has now been completed and permanently archived.
