Scientific question

Can a directed road-topology graph combined with a learned adaptive graph improve hourly +1h/+2h/+3h/+6h traffic forecasts while retaining calibrated uncertainty and resilience to sensor failures?

Physical graph

Sensor relationships can be derived from geographic kNN or a directed drivable OpenStreetMap network.

Adaptive graph

Node embeddings learn additional predictive dependencies that static road topology may miss.

Uncertainty

Quantile outputs expose interval coverage and width instead of hiding uncertainty behind a point estimate.

Multi-horizon

Evaluation is explicitly separated across +1, +2, +3, and +6 hours for the hourly source data.

Failure resilience

Random and structured 10/20/30% sensor outages quantify robustness.

Evidence first

Research findings are generated from machine-readable experiment outputs, never invented in HTML.
