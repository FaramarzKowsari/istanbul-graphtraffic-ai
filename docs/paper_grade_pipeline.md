# Paper-grade pipeline

1. Data audit and raw-file hashes.
2. Sensor inclusion/exclusion report.
3. Missingness map and temporal coverage.
4. Graph audit: node/edge counts, connectedness, path statistics, bridge/tunnel attribution where available.
5. Frozen chronological splits.
6. Baseline benchmark.
7. Proposed-model benchmark.
8. Ablation study.
9. Sensor-failure study.
10. Calibration study.
11. Spatial error analysis.
12. Statistical comparison with multiplicity control where appropriate.
13. Machine-readable tables, figures, model card, dataset card, and artifact hashes.
14. Manuscript + repository release + archival DOI.
