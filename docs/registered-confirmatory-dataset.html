Provenance and reproducibility

The confirmatory analysis derives from the public Istanbul Metropolitan Municipality (İBB) Hourly Traffic Density data source. Protocol v2 used 2024-05 and 2024-11 as the analyzable confirmatory months. January 2025 was excluded from confirmatory inference because it had been used during exploratory development.

The inferential protocol used paired calendar-day comparisons, a one-sided paired Wilcoxon signed-rank test for the registered directional hypotheses, Holm correction for the secondary hypothesis family, and a 10,000-replicate hierarchical bootstrap with fixed seed 20260814.

Source registration: 10.17605/OSF.IO/FM5R7. Versioned project archive: 10.5281/zenodo.21916357.
